# Skynet Installers

The public site hosts the current Skynet installation packages:

- [Skynet Installers](https://matteo-avigni.github.io/Skynet-Downloads/)

Publication is intentionally limited to the Authenticode-signed Windows MSI,
the Developer ID signed and notarized macOS PKG, SHA-256 checksums, and signed
update-feed metadata. This repository does not use GitHub Releases or publish
portable application archives. The Skynet application source remains private.
